Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 29 September 2026 • Versi Dokumen 1.1

1. Arsitektur Offline-First & Penyimpanan Lokal

Aplikasi Dasbor Pribadi dibangun dengan prinsip Offline-First dan Zero-Knowledge. Seluruh catatan keuangan (transaksi, dompet, tabungan, anggaran belanja) dan produktivitas (tugas harian, sub-tugas, kalender) tersimpan secara default di penyimpanan internal perangkat Anda (melalui localStorage dan Cache Storage browser). Pengembang tidak memiliki akses langsung ke perangkat Anda atau catatan keuangan pribadi Anda.

2. Layanan Cloud Opsional (Google Firebase)

Penyimpanan Cloud bersifat sepenuhnya opsional. Jika Anda memilih untuk masuk menggunakan akun Google Anda:

  • Hanya email dan ID akun Google Anda yang digunakan untuk otentikasi aman melalui Google Firebase Authentication.
  • Data keuangan Anda disinkronkan ke basis data Google Cloud Firestore khusus akun Anda sendiri agar Anda dapat mengakses data antar-perangkat.
  • Kami tidak pernah membagikan, menyewakan, atau menjual data Anda kepada pihak ketiga mana pun.

3. Kebijakan Cookie & Pelacak Pihak Ketiga

Aplikasi ini tidak menggunakan cookie pelacak iklan, analitik pihak ketiga komersial, maupun pixel pelacak perilaku. Satu-satunya penyimpanan yang digunakan adalah localStorage dan sessionStorage teknis yang diperlukan secara mutlak agar aplikasi dapat mengingat tema tampilan (Dark/Light mode), pilihan bahasa (ID/EN), dan saldo keuangan Anda secara offline.

4. Hak Pengguna & Kontrol Penuh Data

Anda memegang kendali 100% atas data Anda:

  • Ekspor Cadangan: Anda dapat mengunduh seluruh data dalam format JSON standar kapan saja dari menu Pengaturan.
  • Reset Selektif / Hapus Data: Anda dapat menghapus data tertentu (transaksi saja, tugas saja) atau menghapus seluruh basis data lokal dalam satu klik via fitur Reset Selektif.
  • Pencabutan Izin Cloud: Anda dapat keluar (*Sign Out*) kapan saja untuk menghentikan sinkronisasi cloud.

5. Keamanan & Enkripsi

Seluruh transmisi data saat menggunakan fitur cloud dilindungi oleh enkripsi standar industri modern (Transport Layer Security / HTTPS) serta aturan keamanan ketat Firebase Security Rules yang membatasi akses baca dan tulis hanya kepada pemilik akun yang terotentikasi.

6. Kontak & Pertanyaan

Jika Anda memiliki pertanyaan mengenai kebijakan privasi atau ingin mengajukan penghapusan akun data cloud, Anda dapat menghubungi kami melalui repositori resmi di GitHub: github.com/habielmaulanaaa-svg/dasbor-pribadi.

1. Offline-First Architecture & Local Storage

Dasbor Pribadi is designed with an Offline-First and Zero-Knowledge architecture. All financial records (transactions, wallets, savings goals, monthly budgets) and productivity entries (tasks, subtasks, activity calendar) are stored by default on your device's internal browser storage (using localStorage and Cache Storage). The developer has no direct access to your device or your personal records.

2. Optional Cloud Services (Google Firebase)

Cloud synchronization is entirely optional. If you choose to sign in using your Google account:

  • Only your email and Google user ID are used for secure authentication via Google Firebase Authentication.
  • Your financial data is backed up to Google Cloud Firestore under your individual user partition so you can sync records across devices.
  • We never sell, rent, share, or monetize your personal data with any third parties or advertisers.

3. Cookies & Third-Party Trackers

This application does not use tracking cookies, advertising pixels, or third-party behavioral analytics. The only client storage utilized is technical localStorage and sessionStorage strictly required to preserve user settings (Dark/Light mode, language selection, and offline financial balances).

4. User Rights & Data Control

You retain 100% control over your data:

  • Data Export: You can download your complete data record as a standard JSON file at any time from the Settings menu.
  • Selective Data Reset: You can wipe specific segments or erase all local databases with a single tap using the Selective Reset feature.
  • Cloud Authorization Revocation: You may sign out at any time to immediately halt cloud synchronization.

5. Security & Encryption

All data transmission for cloud sync is safeguarded with modern industry-standard Transport Layer Security (HTTPS) and rigorous Firebase Security Rules that restrict read and write privileges solely to the authenticated account owner.

6. Contact & Inquiries

If you have questions regarding this Privacy Policy or wish to request cloud data deletion, please contact us through the official GitHub repository: github.com/habielmaulanaaa-svg/dasbor-pribadi.
